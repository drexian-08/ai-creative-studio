# Prompt Library

Copy a prompt and change the square-bracket details. You can use Malay or English.

## 1. Start any creative project

I am a beginner. Help me create [project idea] for [audience/platform]. First inspect the current project and my available tools. Explain the best low-cost workflow, then create a short brief and a small milestone plan. Do not make large changes before I approve the direction.

## 2. Realistic game prototype

Help me build a small playable prototype for [game concept] using the most suitable engine for my computer. Prioritize believable movement, responsive controls, readable visuals, and stable performance. Start with one small level and one core mechanic. Explain how to run and test it.

## 3. Smooth character animation

Review the character rig and animation setup. Improve idle, walk, run, start/stop, jump, fall, and landing transitions as appropriate. Check foot sliding, pose popping, clipping, and responsiveness. Tell me exactly which files or settings changed and how I can preview them.

## 4. 3D animated short

Create a production plan for a [duration]-second 3D animation about [topic]. Include a concise story, storyboard, camera, character actions, lighting direction, audio, and a low-cost preview workflow. Keep the first version simple enough to render on my hardware.

## 5. Short video editing

Help me make a [duration]-second video for [platform] about [topic]. Create a hook, scene-by-scene timeline, natural dialogue/voiceover, captions, sound plan, and export settings. Do not invent product claims or use unlicensed media.

## 6. Educational content for children

Create a safe and engaging [duration]-minute learning activity for children aged [age] about [topic]. Use simple Malay, short sentences, familiar examples, a fun interaction, and a short knowledge check. Avoid collecting personal information or suggesting unsafe activities.

## 7. Storyboard from product photos

Study the supplied product photos and identify only functions that are visibly supported or explicitly described by me. Create a [duration]-second storyboard with shot duration, camera angle, action, natural Malay voiceover, captions, and sound. Do not misrepresent how the product works.

## 8. Fix a bug safely

Inspect the error and relevant files. Explain the likely cause in simple language. Make the smallest safe change, preserve unrelated working features, and run the available checks. Show me what changed and what I should test manually.

## 9. Optimize for a modest laptop

Review this project for performance on Ryzen 3 7320U, Radeon 610M integrated graphics, 8 GB RAM, and 512 GB SSD. Identify measured bottlenecks if profiling data exists; otherwise label estimates clearly. Recommend the highest-impact low-cost changes first.

## 10. Final quality check

Review the project for functionality, visual consistency, animation quality, audio, captions, accessibility, age suitability, licensing, performance, and export correctness. Rank issues by severity and give exact fixes. Do not claim to have tested anything you could not actually run or inspect.
