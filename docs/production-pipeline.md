# Creative Production Pipeline

A repeatable workflow for taking an idea to a finished game, animation, or video. Use only the stages relevant to the project; do not force every project into every stage.

## 1. Discover
Capture the audience, goal, platform, duration/genre, language, references, budget, deadline, available assets, and hardware. If details are missing, make safe assumptions and label them.

## 2. Brief
Write a one-page creative brief containing:
- Working title and one-sentence concept
- Target audience and intended experience
- Learning/message goal (if educational)
- Style direction and references described as general traits
- Deliverables, dimensions, duration, platform
- Constraints, risks, and acceptance criteria

## 3. Plan
Create a storyboard, shot list, game design outline, asset list, and milestone checklist. Estimate effort in small tasks. Identify dependencies and licensed assets.

## 4. Prototype
Make the smallest end-to-end slice:
- Game: one playable area, one core mechanic, temporary art/audio.
- Animation: one short shot with blocking, camera, and rough timing.
- Video: a rough cut with placeholder titles/audio.
- Educational content: one complete mini-lesson with an example and comprehension check.

## 5. Produce
Create assets and implement the plan. Keep editable project files. Use consistent naming and folders. Record asset sources, licenses, and generation prompts when relevant.

## 6. Review
Check function, story clarity, visual continuity, motion, audio, captions, accessibility, factual accuracy, age suitability, performance, and export settings. Log issues by severity and fix blockers first.

## 7. Deliver
Export to the requested format, verify the actual exported file, and provide:
- Final file(s) and editable source location
- How to open/run/play
- Controls or viewing notes
- Software/dependencies and versions
- Tests/review performed
- Known limitations and next steps

## Suggested project layout
- project-name/
  - brief.md
  - README.md
  - references/
  - source/
  - assets/audio/
  - assets/images/
  - assets/models/
  - assets/video/
  - storyboards/
  - scenes/
  - exports/
  - notes/
  - licenses/

## Hardware-aware production
For an 8 GB RAM integrated-GPU laptop, start with low-resolution previews, small scenes, compressed textures, simple lighting, short clips, proxies, and modest sample counts. Close unnecessary apps and save versions. Use cloud services only when the user agrees and understands any cost/privacy implications. Do not promise real-time performance without measuring it.
