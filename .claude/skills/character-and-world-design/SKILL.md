# Character and World Design

## Workflow
1. Identify genre, audience, tone, setting, gameplay/story role, and technical limits.
2. Define visual pillars (3–5 memorable qualities) and a concise palette/material direction.
3. Design silhouettes and proportions before surface detail.
4. Specify front/side/back views or equivalent references when consistency matters.
5. Define materials, scale, wear, color, accessories, and animation constraints.
6. Check readability at intended camera distance and target resolution.
7. Record reusable rules in an art bible so assets remain consistent.

## Originality and rights
Create original designs. Do not reproduce protected characters, logos, or distinctive branded assets. Avoid requests to imitate a living artist's exact style; translate references into high-level traits instead.

## Deliverables
Include design rationale, shape language, palette/material notes, scale, key variants, and implementation considerations.
