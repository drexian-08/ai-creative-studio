# Open the Studio Dashboard

The dashboard is a lightweight static web app. It does not need Node.js, Python packages, an API key, or an internet connection after you have the file.

## Easiest way

1. On the repository page, choose **Code → Download ZIP**.
2. Extract the ZIP on your computer.
3. Open the extracted folder, then open `studio/index.html` in Chrome or Edge.
4. Fill in the project idea and press **Bina pelan projek**.
5. Copy the generated prompt and paste it into your AI coding assistant (Codex, Claude Code, or Copilot).

## What it does today

- Builds a creative brief from your project details.
- Produces a step-by-step production plan.
- Creates a ready-to-copy prompt for an AI assistant.
- Exports the plan as a Markdown file.
- Works locally in your browser; the form content is not uploaded anywhere.

## What it does not do yet

The dashboard does not itself generate images, 3D models, video, sound, or playable games. It prepares a plan and prompt for an AI assistant. Actual generation/editing requires suitable software or connected AI services.

## Privacy note

Do not place passwords, API keys, private personal details, or children's personal information in project descriptions. If you later publish the dashboard publicly, remember that a public website can be visited by anyone.
